# Black Cat English

Браузерный курс английского для 3 класса (по программе Spotlight 3). Герои: Black Cat, Reka (девочка-капибара), Doctor Plus и Susan.

## Как открыть

- **Локально:** запустите в папке курса `python3 -m http.server 8000` и откройте http://localhost:8000. Можно и просто дважды щёлкнуть `index.html`, но картинки из `img/` надёжнее грузятся через сервер.
- **GitHub Pages:** загрузите содержимое папки в репозиторий, затем Settings → Pages → Deploy from branch → `main` / `root`. Сборка не нужна.

Лучше всего работает в **Chrome**: там есть хорошие английские голоса и распознавание речи.

## Как устроено

- `data/course.js`: герои и план из 12 уроков (маршрут такси Сьюзан).
- `data/lessonNN.js`: содержимое урока. В каждом есть `class` (занятие с папой, со сценарием в поле `teacher`) и `home` (домашка).
- `js/`: движок. `exercises.js` отвечает за типы упражнений, `store.js` за прогресс и повторение, `speech.js` за голос.
- `img/`: иллюстрации в WebP 512 px (карточки `w_<слово>`, герои `char_<id>`). Сгенерированы через Figma MCP, промпты в `prompts/illustrations.md`. Курс ищет картинку по имени в порядке webp → png → svg → jpg, если файла нет, показывает эмодзи.
- `art_full/`: оригиналы 1024 px (в git не попадают, см. `.gitignore`).

## Прогресс

Прогресс хранится в браузере (localStorage). В разделе «⚙️ Для родителей» его можно сохранить в файл и восстановить.

- **Слова:** слово считается выученным, когда она узнала его правильно в 3 разных дня. Повторение по интервалам 1, 2, 4, 7, 14 дней.
- **Слух, грамматика, чтение:** лучший результат с первой попытки по каждому уроку, в доле от всего курса (12 уроков).
- **Звёзды урока:** ★ занятие пройдено, ★ домашка сделана, ★ домашка на 90% и выше.

## Ученики и облачное сохранение

При первом открытии курс спрашивает имя и создаёт профиль ученика. У каждого профиля свой прогресс. Кнопка «это не я» рядом с именем на карте переключает ученика. Голос, скорость и токен — это настройки компьютера, они общие для всех профилей.

Прогресс копируется в **приватный** репозиторий GitHub `english-progress`: один файл на ученика, `progress/<id>.json`. Курс записывает его через ~8 секунд после изменений и сразу, когда вкладку закрывают или переключают. При открытии курс подтягивает свежую версию и сливает её с локальной, ничего не теряя. Без интернета прогресс копится в браузере и уходит в облако позже.

**Настройка (один раз на каждом компьютере):**
1. Создайте токен: GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
   - Repository access: **Only select repositories** → `english-progress`.
   - Permissions → Repository permissions → **Contents: Read and write** (Metadata: Read-only включится сам).
   - Срок действия — на ваш выбор (например, 1 год). Когда истечёт, курс покажет «⚠️ не сохранилось в облако», прогресс при этом не пропадёт.
2. В курсе откройте ⚙️ «Для родителей» → «Облачное сохранение»: владелец — ваш логин GitHub, репозиторий — `english-progress`, токен — вставьте. Нажмите «Проверить».
3. На втором компьютере сделайте то же самое — на экране «Как тебя зовут?» появится ученик из облака, выберите его.

Токен хранится только в этом браузере и отправляется только в api.github.com. Он даёт доступ только к репозиторию с прогрессом.

**Ручная правка прогресса:** отредактируйте файл ученика в `english-progress` и добавьте `"replace": true`. При следующем открытии курса эта версия заменит ту, что в браузере.

## Как добавить урок

1. Скопируйте `data/lesson01.js` в `data/lesson02.js`, поменяйте `n: 2`, слова и шаги.
2. Подключите файл в `index.html` после `lesson01.js`.

Типы шагов: `cards`, `scene`, `listen_pick`, `read_pick`, `pick_word`, `match`, `fill`, `build`, `spell`, `listen_who`, `story`, `rule`, `offline`, `speak`.
